## `oven-bp14b-d4.4-24.json`

В задании было два товара, но во входном PDF был только один пример. Второй товар
взят из XML-выгрузки, которую предоставил заказчик:

```xml
<offer id="54113" available="true" group_id="7857">
  <name>БП14Б-Д4.4-24</name>
  <typePrefix>блок питания 2-х или 4-х канальный</typePrefix>
  <url>https://www.souz-pribor.ru/product/bp14b-d4/</url>
  <categoryId>329</categoryId>
  <vendor>ОВЕН</vendor>
  <vendorCode>70365</vendorCode>
  <price>6832</price>
  <currencyId>RUR</currencyId>
  <param name="Артикул">70365</param>
  <param name="Код товара">16515</param>
</offer>
```

XML содержит две модификации: `БП14Б-Д4.2-24` (2 канала) и `БП14Б-Д4.4-24`
(4 канала). Для примера выбрана 4-канальная версия. Технические характеристики и
описание дополнены только данными со страницы товара, указанной в XML:
<https://www.souz-pribor.ru/product/bp14b-d4/>. Цена и складские остатки в карточку
не включались: это не технические характеристики.
